# TactoHand

### Learning Geometry-Based Dense Hand-Surface Interaction Fields from Video

[Paper (arXiv)](https://arxiv.org/abs/2610.39585)

TactoHand predicts dense contact, proximity and 3D force fields on the hand
surface from monocular video. It combines temporal visual modeling with
geometry-based supervision and differentiable physics constraints.
