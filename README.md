## Overview

TactoHand estimates dense **contact**, **proximity** and **3D force** fields on
the hand surface from monocular video. Temporal visual modeling combines with
geometry-based supervision and differentiable physics constraints to capture
hand–object interactions.

> **Release status:** This repository currently contains paper information and
> the release roadmap. The project website, source code, pretrained checkpoints
> and dataset have not been released. All roadmap items are pending.
