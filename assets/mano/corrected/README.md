# Corrected MANO models

Only the left model has corrected x shapedirs. The right model is a relative
link to the stock right model. Load through the shared MANO boundary to avoid
an unconditional second flip. Existing dataset parameters are not converted
by moving or selecting these files.

Original export manifest and numerical verification are preserved verbatim in
`provenance/manifest.json` and `provenance/verification.json`.
